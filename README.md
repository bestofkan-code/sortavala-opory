# Карта опор освещения, Сортавала

Веб-карта опор наружного освещения с отметкой хода работ и общей онлайн-базой Supabase.

- `index.html` — стартовая страница с выбором режима
- `redaktor.html` — редактор: отметка работ, правка, добавление и перенос опор, рисование, отчёты, история изменений
- `prosmotr.html` — только просмотр, данные обновляются автоматически
- `supabase_schema.sql` — схема таблиц `poles`, `draws`, `history` для новой базы
- `android/` — Android-приложение

Сайт: https://bestofkan-code.github.io/sortavala-opory/

## Android-приложение «Опоры Сортавала»

Для Android 8 и новее. Внутри открывается тот же редактор карты с сайта, поэтому все изменения карты попадают в приложение без переустановки. Без интернета открывается последняя загруженная копия.

Приложение добавляет то, что в браузере телефона работает плохо: сохранение Excel, PDF и писем в «Загрузки», печать, доступ к GPS, выбор файла для загрузки данных.

**Скачать APK:** https://github.com/bestofkan-code/sortavala-opory/releases/download/android-latest/sortavala-opory.apk

APK собирается автоматически (GitHub Actions, `.github/workflows/android.yml`) при изменении `android/` или `redaktor.html` и выкладывается в релиз `android-latest`.

### Подпись APK

Чтобы обновления ставились поверх старой версии, все сборки должны быть подписаны одним ключом. Ключ хранится в секретах репозитория (Settings → Secrets and variables → Actions):

- `ANDROID_KEYSTORE_B64` — файл ключа `.jks`, закодированный в base64
- `ANDROID_KEYSTORE_PASSWORD` — пароль ключа (алиас `opory`)

Без секретов сборка тоже проходит, но подписывается временным ключом, и каждую новую версию придётся ставить после удаления старой.
