# Сборка страниц из redaktor.html

Основной файл — `redaktor.html`. Остальные страницы собираются из него:

```
sed 's#const RO=/\*RO\*/false;#const RO=true;#' redaktor.html > prosmotr.html
python3 tools/patch_tn.py redaktor.html tools/tn_remarks.json zamechaniya.html
python3 tools/patch_tn.py prosmotr.html tools/tn_remarks.json zamechaniya-prosmotr.html
python3 tools/patch_crew.py redaktor.html montazh.html     # «монтажная карта» для бригады монтажников (использует tools/crew.js)
python3 tools/patch_zones.py redaktor.html uchastki.html   # «Участки работ»: письма и схемы по участкам (использует tools/zones.js)
```

`montazh.html` («монтажная карта») — вход только для учётной записи бригады (`montazh@…`, роль `crew` в Supabase). Кронштейны на значке опоры там рисуются крупнее, с белой обводкой и цветом по типу (1-рожк. — тёмный, 2-рожк. 90° — оранжевый, 180° — фиолетовый; пунктир — не установлен), легенда — в панели.
Сервер разрешает этой роли менять только работы 5 (СИП), 6 (светильник), 12 (кронштейн), 14 (подрезка крон бригадой — отдельно от нашей 9),
комментарий по работам, длины СИП по пролётам (таблица spans) и на ТП — «Проложен бронекабель» и длину кабеля.

Таблица «Контракт и выполнение» в шапке: `python3 tools/patch_main_contract.py redaktor.html` (уже применено) — опоры по типам (397/183/5/7), закладные (402/190), кронштейны (353/50/189), светильники (831): контракт / на карте / сделано / осталось. На монтажной карте скрыта.

СИП-карта (кнопка под таблицей «Контракт и выполнение»): `python3 tools/patch_main_sip.py redaktor.html` (уже применено; код в `tools/sip.js`) — магистраль и ответвления, длины пролётов, роль опоры на линии, расчёт арматуры и Excel.

Фильтр «Опоры» (стандартные/анкерные, 8/9 м): `python3 tools/patch_main_ptype.py redaktor.html` (уже применено).

Задания бригаде: `python3 tools/patch_main_tasks.py redaktor.html` (уже применено; код в `tools/tasks.js`).
В основной карте режим «Задания бригаде» — выделить опоры, виды работ, срок → таблица `crew_tasks`;
на монтажной карте задания показаны в панели «Задания» и кольцами вокруг опор.

Участки работ (`uchastki.html`, код в `tools/zones.js`): выделить опоры участка (нажатием или обводом), даты и время, виды работ и что нужно —
освободить места у опор (письмо в пресс-службу + объявление для жителей), отключение ВЛ 0,4 кВ (письмо в Россети), автовышка на проезжей части (письмо в ГИБДД).
Кнопка «Документы» собирает архив в папке «Участок <название> <даты>»: схема участка (PDF, A4) и письма (DOCX). Реквизиты писем — кнопка «Реквизиты писем» (хранятся в браузере).
Участки хранятся в таблице `work_zones` (если её нет — только в браузере):
```sql
create table if not exists public.work_zones(id text primary key, name text not null, uids text[] not null default '{}', works int[] not null default '{}',
 d1 date, d2 date, t1 text, t2 text, lift boolean not null default false, road boolean not null default false, outage boolean not null default false,
 park boolean not null default true, note text, sent jsonb not null default '{}'::jsonb, done boolean not null default false, ed text, updated_at timestamptz not null default now());
alter table public.work_zones enable row level security;
create policy wz_read on public.work_zones for select to anon, authenticated using (true);
create policy wz_write on public.work_zones for all to authenticated using (not public.is_crew()) with check (not public.is_crew());
```

- `patch_main_brackets.py` — блок «Проверка кронштейнов» под «Контракт и выполнение»: по ТП 1-рожк./90°/180° (установлено из всего), тип не указан, «можно ставить», замечания по опорам (нажать — карта покажет опору), выгрузка «Таблица проверки (Excel)».
- `patch_main_fundament.py` — блок «Проверка котлованов, закладных, бетона» (после patch_main_brackets.py): по ТП котлованы / закладные / бетон (сделано из всего), «→закл.», «→бет.», замечания (нет котлована под закладной, нет бетона под опорой, даты не по порядку, работы на исключённых и гравитационных), выгрузка в Excel.
- `patch_main_plan.py` — «План работ»: задания с порядком обхода (котлованы / закладные / бетон и др.), кнопка «Порядок обхода», блок вверху панели — номера опор на карте, следующая опора, маршрут в Яндекс Картах. Бригаде на монтажной карте планы по фундаментам не показываются.
- `patch_main_plan_edit.py` — правка плана на карте (после patch_main_plan.py): «Изменить план» — нажимать на опоры (добавить на выгодное место / убрать), ↑ ↓ ✕, «Рядом ещё не сделано», «Пересчитать порядок», название и дата; «+ Новый план бурения».
- `patch_pdf_sip.py` — PDF общего плана: в сводке «СИП протянут: ≈ N м (пролётов)» и за период фильтра дат (пролёт — когда «Протянут СИП» отмечен на обеих опорах, длина по СИП-карте).
- `patch_brackets_smeta.py` — рожки кронштейнов крупнее и в цвет типа; «Проверка кронштейнов»/«котлованов» без серых опор; «Сверка со сметой» (592 опоры, 353 / 50 / 189) и «Подсказки до сметы» с кнопкой «Применить».
- `patch_hide_plan.py` — блок «План работ» убран (скрыт, маршрут не рисуется).
- `patch_tp_colors.py` — пролёты в цвет своей ТП (между ТП — тёмно-серый), значок ТП обведён её цветом, цвета ТП в легенде.
- `patch_kc_add.py` — новая опора сразу получает тип кронштейна, оставшийся по смете (1-рожк. → 180° → 90°), подсказка «по смете осталось»; предупреждения сверх сметы и сверх 592 опор.
- `patch_rl_toggle.py` — линии совместной подвески по кнопке «СП» на карте (выкл. — только красные точки у опор).
- `patch_nb.py` — кнопка «Не забетонированные»: только опоры с отметками «Забурен котлован» и «Установлена закладная» без «Забетонирована».
- `patch_gray_only.py` — кнопка «Только серые (предполагаемые)»; с «Не забетонированными» не совмещается.
- `patch_nk.py` — кнопка «Не забурены котлованы»: только опоры без отметок «Котлован» и «Закладная» (без исключённых, серых, гравит.); с «Не забетонированными» и «Только серые» не совмещается.
- `patch_no_gray_counts.py` — серые (предлагаемые) опоры не участвуют в подсчётах: контракт и выполнение, кронштейны и светильники, высоты, «нет на карте», счётчик по фильтру, кронштейны на монтажной карте.
- `patch_progress_more.py` — «Ход работ»: светильники из 831, кронштейны по типам из 353/50/189, СИП протянут ≈ м из 16 664 м.
- `.github/workflows/cleanup-tmp.yml` — удаляет временные ветки `tmp-*`: сразу при push с «[удалить]» в сообщении (файл сценария должен быть в ветке), каждый час — старше 30 мин, вручную — Run workflow.
- `patch_materials.py` — блок «Материалы на складе»: поставки из таблицы `materials_in` (пришло), расход по карте на смонтированное (ушло), остаток. Видят только редакторы.
- `patch_od.py` — поле «Старая опора» в карточке опоры (колонка poles.od: d — демонтируется, k — остаётся); в просмотре — строка в карточке.
- `patch_tree_main.py` — подрезка крон бригады (работа 14) на основной карте и в просмотре: блок «Подрезка крон — бригада» (опоры, даты, фото до/после, нажать — карта покажет опору) и фотоотчёты «подрезка бригады» и «вся подрезка: наша + бригада» (ТП и даты из фильтра). На монтажной карте скрыт.
- `patch_materials2.py` (после patch_materials.py) — «Материалы на складе»: расход крюков (на анкерный и поддерживающий зажим), ленты (1,5 м на крюк), бугелей (1 на метр ленты), проколов CT 16 P (светильники ×3 + перемычка PEN); позиции с одним ключом (напр. PA 4/35 и PA 25 S, две марки СИП) — одной строкой.
- `patch_ar.py` — арматура СИП на опоре (колонка poles.ar: {a — анкерных зажимов, s — промежуточных подвесов, d — дата}): блок «Арматура СИП на опоре» с − / + и «= по расчёту» (из СИП-карты) в карточке монтажной карты и редактора, в просмотре — строка. Бригада может менять ar (crew_guard_poles), pole_patch пишет ar. На монтажной карте в сводке — «Анкерных зажимов» и «Промежуточных подвесов» (отмечено / по расчёту), в Excel «По опорам» — колонки.
- `patch_ar2.py` (после patch_ar.py) — арматура на опоре v2: вручную крюк, анкерный зажим, прокол СИП–СИП (шаг 4); подвес промежуточный — автоматически, если на опоре отмечен «СИП» и нет анкерного зажима. «= по расчёту» ставит крюки, анкерные и проколы из СИП-карты. В сводке и Excel бригады — все четыре позиции.
- `patch_ar3.py` (после patch_ar2.py) — подвес промежуточный можно поставить вручную (− / +, хранится ar.s); «авто» возвращает автоматический (СИП протянут и нет анкерного).
- `patch_coords.py` — координаты опоры в карточке редактора и просмотра (и в картах, собранных из редактора): «61.712345, 30.691234» — широта, долгота, как вставляет поиск Яндекс Карт; кнопка «Копировать» и ссылка «Яндекс» (открывает точку на Яндекс Картах).
- `patch_ar_hide.py` — блок «Арматура СИП» в окне опоры скрыт на основной карте (редактор, просмотр, замечания, участки); на монтажной карте (montazh) остаётся. Флаг AR_SHOW по имени страницы.
- `patch_compact.py` — окно опоры компактнее: плитки работ и поля ниже, галочки «заземл. / совм. подв. / ввод КЛ» в одну строку; на экране от 700 px окно 420 px и работы в 3 колонки.
- `patch_tw.py` — работа ТП №2 называется «Установлен ШУНО». На монтажной карте в окне ТП бригада теперь отмечает и «Проложен бронекабель», и «Установлен ШУНО» (patch_crew.py); в базе crew_guard_tps пропускает от бригады ключи w 1 и 2 и длину кабеля.
- `patch_tp_photo.py` — фотоотчёт по ШУНО в окне ТП (редактор и монтажная карта — добавить/удалить, просмотр — только смотреть). Фото в pole_photos: uid «tp:<ТП>», k=2, kind='after'; бакет pole-photos.
- `patch_heic.py` — фото HEIC/HEIF (iPhone) во всех полях загрузки фото: если браузер не открывает HEIC сам, файл переводится в JPEG через heic2any (подгружается с jsdelivr только при первом HEIC), затем обычное сжатие до 1600 px. В patch_tn.py tnShrink тоже идёт через heicFix. В выборе файла разрешены .heic/.heif.
- `patch_heic2.py` — HEIC переводится библиотекой heic-to 1.6.7 (libheif 1.23); старый heic2any 0.0.4 давал «ERR_LIBHEIF format not supported» на фото новых iPhone, оставлен запасным. Если не вышло ни тем, ни другим — понятная ошибка с советом снимать в JPEG.
- `patch_vf.py` — сверка котлованов на месте (колонка poles.vf): в окне опоры блок «Сверка на месте» — галочка «котлован на месте, точка верна», фактическая закладная ЗФ-24/8 / ЗФ-30/8, «Точка не там — поставить по GPS» (опора сразу переносится в точку телефона), комментарий. Кольцо на значке: зелёное — сверено, оранжевое — расхождение (другая закладная или перенос ≥ 3 м). Кнопка «Не сверены котлованы», счётчик «сверено N из M, расхождений K», «Excel: сверка» (расхождения / не сверены / сверенные). На монтажной карте и в просмотре блока нет, в просмотре — строка в карточке.
- `patch_nozoom.py` — на телефонах масштабируется только карта, не вся страница: viewport maximum-scale=1, user-scalable=no; в Safari отменяются жесты масштаба страницы; у окна опоры touch-action pan-x pan-y. Раньше iPhone увеличивал страницу при вводе в поле и при щипке поверх окна опоры — окно меняло масштаб.
- `patch_card2.py` (после patch_vf.py) — окно опоры компактнее: параметры опоры свёрнуты в строку-сводку (✎ — раскрыть, запоминается; открыто само, если у 2-рожк. кронштейна не указан угол); сверка — одна строка «✓ Всё верно / 📍 GPS / ≠»; работы — 3 колонки, только относящиеся к опоре и выполненные, остальные под «Ещё работы (N)»; координаты — в «Ещё». На телефоне (< 700 px) окно опоры — панель снизу во всю ширину (полоска сверху: нажать/потянуть вверх — выше, вниз — ниже или закрыть), карта сдвигается, чтобы опора была над панелью.
- `patch_card2b.py` (после patch_card2.py) — ✎, «≠», «Ещё работы» больше не закрывают окно опоры на компьютере: перерисовка после обработки нажатия (иначе Leaflet считал нажатие кликом по карте).
- `patch_card3.py` (после patch_card2b.py; редактор, замечания, участки) — окно опоры узкое (212 px), быстрый набор: тип опоры Стандартная/Анкерная, кронштейн нет/1-р/90°/180°, старая опора нет/демонт./остаётся, отметки Опора/Светильник/СИП/Совм. подв./Заземл. (светильников — по кронштейну: 0/1/2), сверка, ⧉ — координаты. «Работы N/14» раскрывает все работы, «Ещё» — высоту, фундамент и прочее. На телефоне — панель справа, карта слева видна.
- `patch_mfull.py` — телефон: кнопка внизу слева на карте «▼ Скрыть таблицы» / «▲ Таблицы» — убирает нижнюю панель, карта на весь экран; состояние запоминается. На экранах шире 700 px кнопки нет.
- `patch_mfull2.py` (после patch_mfull.py) — кнопка и на компьютере: «◀ Скрыть панель» / «▶ Панель» прячет левую панель, карта на всю ширину.
- `patch_hinline.py` — «История» в окне опоры раскрывает историю прямо в окне (последние 40 изменений), окно не закрывается; «Вся история в панели» — прежний просмотр.

- `patch_dense.py` — окно опоры плотнее (только CSS): шрифт 11 px, плитки работ 21 px, поля 21 px, промежутки 2–3 px, ширина 372 px на компьютере / 268 px на телефоне. Окно примерно на четверть меньше.
